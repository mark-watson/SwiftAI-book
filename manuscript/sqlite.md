# Using SQLite Embedded Relational Database in Swift

For my general programming I use several types of datastores: relational databases (usually SQLite or PostgreSQL), non-relational databases (BigTable, MongoDB, Casandra, DynamoDB, etc.), general graph databases (almost always Neo4J) and RDF data stores that support SPARQL (slightly similar to SQL) queries for semantic web and linked data applications. Later in this book we will touch lightly on using semantic web technologies because of my personal interest in using semantic web technologies for knowledge representation and organizing information (inspired by my work with Google's Knowledge Graph when I worked there and the work for several other consulting customers in the last fifteen years). The material here using SQLite will be used in a few later examples and will likely be useful in your work.
